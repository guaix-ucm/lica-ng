# lica-ng

Workspace for the next generation of reusable LICA utilities for day-to-day software developments. It is structured as proper installable subpackages and avoids the monolith dependency of the former `lica` library, which is slowly being deprecated.

Currently, the following packages are availabe and installable via pip:
* [lica-log](packages/lica-log/README.md)
* [lica-cli](packages/lica-cli/README.md)
* [lica-tables](packages/lica-tables/README.md)
* [lica-sqa](packages/lica-sqa/README.md)
* [lica-raw](packages/lica-raw/README.md)
